# Beating Canvas Heart

A standalone HTML canvas animation that renders a pulsing heart from moving particles.

## Run

Open `beating_canvas_heart_animation.html` in a modern web browser. The page has no build step or external dependencies.

## GitHub Pages

To publish the page with GitHub Pages, rename `beating_canvas_heart_animation.html` to `index.html`, then enable Pages for the `main` branch and root folder in the repository settings.
